# 📊 Dynamic Dashboard

## 📌 Overview
Dynamic Dashboard is an intuitive web application that serves as a user-friendly interface for managing and visualizing data. Built with React and Vite, it features seamless navigation and a mock REST API for data handling. Perfect for developers looking to implement a client-server architecture, this project showcases real-time data updates and state management.

## ✨ Features
- User authentication and login
- Dynamic data visualization on the dashboard
- RESTful API integration using json-server
- Responsive design for mobile and desktop
- Route management with React Router

## 💻 Tech Stack
- React
- Vite
- json-server
- Axios
- Font Awesome
- ESLint

## 🏗 Architecture
- **Project Type:** Client-server application with a responsive UI
- **Main Folders:**
  - `src/`: Contains all React components and logic
  - `public/`: Includes static assets like HTML and images
  - `db.json`: Mock database for json-server

## ▶️ How to Run
1. Install dependencies:  
   `npm install`
2. Start development server:  
   `npm run dev`
